# Thai_Language_Game

A 2D mystery RPG prototype in the spirit of *7 Days to End with You*, except the "unknown language" is real Thai. You wake up with no memory in a wooden house. Everyone speaks Thai. You work out what words mean from context and write your guesses in a journal, and as you get groups of words right they lock in and show how they're pronounced.

## Opening the project

1. Install **Unity 6** (6000.0 LTS) through Unity Hub. Older versions won't work because the scripts use the TextMeshPro that ships inside `com.unity.ugui` 2.0.
2. In Unity Hub choose **Add > Add project from disk** and pick this folder. Unity fills in the rest of `ProjectSettings` on first open.
3. If Unity asks to import **TMP Essentials**, click *Import TMP Essentials* (or use *Window > TextMeshPro > Import TMP Essential Resources*).
4. Open `Assets/Scenes/Prototype.unity` (or use the menu **Thai Mystery > Open Prototype Scene**) and press **Play**.

If the scene ever breaks, **Thai Mystery > Rebuild Prototype Scene** recreates it. The scene only holds one `GameBootstrap` object; everything else (map, characters, camera, UI) is built in code from the JSON files.

## Controls

| Action | Keys |
| --- | --- |
| Move | WASD / Arrow keys |
| Inspect / talk / next line | Space, Z, Enter, or click the message box |
| Pick a dialogue choice | Up/Down then Space, or click |
| Journal | J or Tab (Esc closes) |
| Guess a word | Click any Thai word in a message or a journal card, type, press Enter |

## How the language mechanic works

- Every Thai word you see is added to the journal. Your guess appears under the word in every message from then on.
- Words belong to **groups** (e.g. *bed, window, mirror, door*). A group confirms only when every word in it has been seen and guessed right, so you can't brute-force one word at a time. Confirmed words turn green and reveal a romanization and a short learning note.
- Guesses are matched loosely: case, punctuation and leading "to/a/the" are ignored, and each word lists several accepted answers.
- Thai is normally written without spaces between words. The game's script puts spaces between words so each one can be clicked and studied, the same way the original game separates its glyph-words.

## Changing the content (no code needed)

All content lives in `Assets/Resources/Data`:

- `words.json`: every Thai word with accepted answers, romanization, group and note.
- `dialogue.json`: dialogue lines. Thai text is space separated; lines with no Thai are the protagonist's thoughts and show in italics. Lines can set flags and offer choices.
- `map.json`: the room layout as text rows (`#` outer wall, `=` wall face, `.` floor, `,` rug), the player start, and objects. Each object has rules that pick a dialogue based on flags, so Mali says different things after you try the door or read the letter.

## Art

Placeholder pixel art is generated by `Tools/generate_sprites.py` (Python + Pillow) into `Assets/Resources/Sprites`. Tiles are 32×32. Character sheets use the RPG Maker layout: 3 columns (step, idle, step) × 4 rows (down, left, right, up). Drop in real art with the same names and sizes to replace them.

## Font

Thai text uses **Sarabun** (SIL Open Font License, see `Assets/Resources/Fonts/Sarabun-OFL.txt`). It covers Thai and Latin, and uses the looped letter style taught in textbooks, which helps learners. A dynamic TextMeshPro font asset is created from the TTF at runtime (`ThaiFonts.cs`), so there's no atlas to bake.

Known limitation: TextMeshPro positions Thai vowel and tone marks with the font's mark tables, which works for normal text, but it doesn't do full Thai shaping. A few rare combinations (for example a lower vowel under ฐ or ญ) may not look perfect.

## Code layout

```
Assets/Scripts
  Core/      GameBootstrap (builds the scene), Game (shared refs), GameInput, ThaiFonts, SpriteLibrary
  Data/      JSON data classes, WordBook (guesses, groups, saving)
  World/     GridMap, PlayerController, CharacterSprite, Interactable, CameraFollow
  Dialogue/  DialogueRunner
  UI/        GameUI, DialogueUI, JournalUI, GuessPopup, WordRow, UIFactory
Assets/Editor  pixel-art import settings and the Thai Mystery menu
```

`GameBootstrap` has a *Reset Save On Play* toggle (on by default) so each Play starts fresh; turn it off to keep your guesses between runs. **Thai Mystery > Clear Saved Guesses** wipes them manually.
